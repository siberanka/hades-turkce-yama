# Security / Güvenlik

## English

The installer only changes allowlisted Hades text paths and its own backup/uninstaller files. It rejects unknown source hashes, damaged backups, overlapping edits and paths outside the selected game folder. It does not modify saved games.

When reporting an issue, do not share tokens, complete user profiles, original game files or untrusted executables. A version number, the error message and the affected relative path are usually enough to start an investigation.

Static analysis and passing tests do not prove an executable malware-free. Compare artifact SHA-256 checksums with a trusted release record. Local preview artwork and private research are not release material.

## Türkçe

Kurulum aracı yalnızca paket içinde tanımlı Hades metin dosyalarına ve kendi yedek/kaldırma dosyalarına erişir. Bilinmeyen kaynak dosyalar, bozuk yedekler, çakışan düzenlemeler ve klasör dışına çıkan yollar reddedilir. Oyun kayıtları değiştirilmez.

Bir hata bildirirken erişim anahtarlarını, kullanıcı profilinizin tamamını, orijinal oyun dosyalarını veya kaynağından emin olmadığınız EXE'leri paylaşmayın. Sürüm numarası, hata iletisi ve etkilenen göreli dosya yolu genellikle ilk inceleme için yeterlidir.

Statik inceleme veya temiz test sonucu, bir yürütülebilir dosyanın zararlı yazılım içermediğini tek başına kanıtlamaz. Dağıtılan dosyanın SHA-256 özetini güvenilir yayın kaydıyla karşılaştırın.
